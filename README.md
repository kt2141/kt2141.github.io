## 🛠️ Repository Architecture & Tech Stack
This repository powers a high-performance, single-file interactive web application built with:
* **Frontend UI:** Tailwind CSS, Custom Glassmorphism, 3D Card-Tilt Physics, and Dynamic Interactive Particle Constellation Canvas.
* **Audio & Voice Engine:** Native browser Web Audio API (synthesized tactile sci-fi sound effects and hover hums) + Web Speech API for executive voice greetings.
* **Multimedia Vault:** In-page modal previewers for PDF dossiers, YouTube streams, Google Drive videos, and Instagram Reels (`@aravind.__reddy`).
* **SEO & Entity Graph:** Schema.org `Person` JSON-LD markup and OpenGraph tags optimized for Google Search Indexing and Knowledge Graph entity resolution.
